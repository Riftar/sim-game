# Art reference

## Environment concepts

- [Manggarai after rain](concept/manggarai-after-rain.png). Station-adjacent street, warung, shopfronts, and a walkable alley.
- [Toko galon](concept/toko-galon.png). Checkout, staple shelves, and water-jug storage.

The scene backgrounds were made with ImageGen. Both use a closer camera than the planned three-quarter top-down gameplay view. Use them for palette, street details, and the visual identity of each workplace.
